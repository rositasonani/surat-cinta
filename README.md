# surat-cinta

A romantic love letter page for Dexter with a gentle background melody generated in the browser.

## Run it locally

From the workspace folder, start a simple web server:

```bash
cd /workspaces/surat-cinta
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser and click "Play our song".

## Files

- index.html — the love letter content
- style.css — styling and romantic page design
- script.js — gentle ambient music generated with Web Audio API
- love-photo.svg — photo frame placeholder for your couple picture; replace it with your actual image if you want the exact photo to appear

## Photo

Save your couple photo as `love-photo.svg` or replace the current file with your own image named `love-photo.svg` so it appears in the love letter frame.
